# Changelog

## [0.1.0] — Release 2 (in progress)

### R2A–R2G ✅ Complete

- **R2A** — Search profiles with saved queries, seed-list integration, language/label filters
- **R2B** — Metadata-only GitHub issue discovery with candidate enrichment and dedup
- **R2C** — Static inspection: ZIP archive parsing, allowlisted file extraction, content risk analysis (prompt injection, credential scanning, lifecycle script detection)
- **R2D** — Network expansion design: registry allowlist contracts, approval phrase validation, egress log design
- **R2E** — Install probe dry-run: proposed install command planning from static evidence (Node/Python)
- **R2F** — Test probe design: blocked behind install evidence, design-only contracts
- **R2G** — Decision cockpit: confidence assessment, why-not-GREEN analysis, handoff packages
- **Policy engine** — Mode-gated operation allow/deny/approval with audit logging
- **Docker sandbox probes** — Readonly probes with strict resource limits (no network, no pulls, no writes)
- **Monitor** — Profile-based change detection across runs
- **GITHUB_TOKEN** auth — Bearer token support for authenticated GitHub API access

### R2H 🔄 In Progress

- Adversarial eval suite
